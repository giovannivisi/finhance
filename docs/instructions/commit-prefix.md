| Prefix     | Stands for             | Use when                                                    |
| ---------- | ---------------------- | ----------------------------------------------------------- |
| `feat`     | feature                | adding new functionality                                    |
| `fix`      | bug fix                | correcting broken behaviour                                 |
| `perf`     | performance            | improving speed or efficiency without changing behaviour    |
| `refactor` | refactor               | restructuring code without fixing a bug or adding a feature |
| `chore`    | chore                  | maintenance tasks, dependency updates, config changes       |
| `docs`     | documentation          | README, comments, wikis                                     |
| `test`     | test                   | adding or fixing tests                                      |
| `ci`       | continuous integration | CI/CD pipeline changes                                      |
| `style`    | style                  | formatting, whitespace — no logic change                    |
